# Backend Engineer Portfolio Template

Next.js (App Router) + TypeScript + Tailwind CSS で構築した、ダークモード基調のポートフォリオ雛形です。

## Sections

- Hero (経歴サマリー)
- Skills (TypeScript / React / Java / PHP-Laravel など)
- Projects (案件一覧)
- Career (職務経歴)
- Contact (お問い合わせ導線)

## Local Development

```bash
npm install
npm run dev
```

ブラウザで `http://localhost:3000` を開いて確認できます。

## Operation Notes

- 起動/停止手順、トラブル対応ログは `docs/dev-runbook.md` にまとめています。
